# fb-photo

Photos are still Facebook's most shareable format for local businesses,
families and events. The first image decides whether the rest get seen.

## Before you start

Read `~/.claude/facebook/voice.md`. Ask what the photos are (or look at them
if attached), and what the post is for: sell, show proof, recap, or tell a story.

## Single photo vs multi-photo

- **One photo** when there's one moment worth stopping for.
- **2-5 photos** (grid layout) when the set tells a story: before/after,
  process, a product range. The first photo is the cover and is shown largest.
- **Album** for event recaps or catalogues people will browse. Albums are for
  browsing, not for reach.

## The cover photo of the post

It does the job a hook does:

- A **face or hands doing something**, or the **finished result**. Not a logo.
- One clear subject, readable on a phone at thumbnail size.
- If text overlay is needed: 6 words max, high contrast, large. Facebook's
  audience skews older; size the text for them.
- Real photos beat stock. Stock reads as an ad and gets scrolled like one.

## Order for a multi-photo post

```
1  the result or the most surprising image
2  the context (where, who)
3-4 the process or details
5  the people (team, customer with permission) or the call to action image
```

## Sizes

- Feed photo: 1080 x 1350 (4:5) takes the most screen on mobile. 1080 x 1080 is safe.
- Multi-photo grid: keep all images the same ratio, or Facebook crops unpredictably.
- Keep key content away from edges; previews crop.

If the user wants files made (resizes, overlays), produce them with an image
library in the workspace and keep originals untouched.

## Text

Write the post text with `/fb-post` (Job A: the photo carries the hook). For
albums, also write a one-line caption per photo; captions on individual photos
are what people read while browsing.

**Alt text for every photo**: what's in it, in one plain sentence.

## Rules

- **Permission** for every identifiable customer or child in a photo. Ask.
- **Never** edit a result photo to look better than the real result.
- No engagement bait ("which one? react ❤️ or 😮").
- Run all text through `/fb-human`. Nothing is posted; the user posts it.
