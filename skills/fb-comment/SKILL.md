# fb-comment

A good comment on the right post is free reach to an audience that already
trusts that poster. A generic one is noise with the user's name on it.

## Read the post first

Ask for the post text (or read it in the user's browser), who posted it, and
the top comments. Then pick a type by what the post **is**:

| the post is... | comment type | shape |
|---|---|---|
| a lesson / tip | **Add a data point** | "Same here: we saw {specific number/result} when..." |
| a question | **Answer it** | the direct answer first, then one line of why |
| a win | **Specific congrats** | name the exact thing that impressed you |
| an opinion | **Respectful extension or disagreement** | "Agree on X. Where I'd push back is Y, because..." |
| a struggle | **Experience, not advice** | "Had the same in 2024. What helped was..." |
| local news / event | **Local detail** | something only a local would add |
| a product / launch | **Concrete question** | a real buyer's question |
| a story | **Your version** | two lines of your own related moment |
| a Group request for recommendations | **Honest recommendation** | only if it's genuinely a fit; disclose if it's your business |

## Rules

- **1-3 sentences.** Facebook comments are read on phones.
- **Specific to this post.** If it could go under any post, rewrite it.
- **No links** unless asked. No "check out my page". No DM-me fishing.
- **Disclose** when recommending your own business in a Group.
- **No emoji-only comments**, no "Great post!", no "So true!", no AI-sounding
  "What a fantastic insight!".
- Better comments signal quality to Facebook's ranking: ones with an opinion,
  a question, or that spark replies.

## Output

Two or three options of different types, each run through `/fb-human`, with a
one-line note on why each fits this post. The user picks and posts. Never
automate commenting; it breaks Meta's Terms and gets accounts blocked.
